เกี่ยวกับนโยบายนี้

นโยบายนี้อธิบายการจัดการข้อมูลของแอพ Jod Note สำหรับ Windows ซึ่งเก็บข้อมูลในเครื่องเป็นหลัก ผู้ใช้จดโน้ตได้โดยไม่ต้องเข้าสู่ระบบ และเลือกเชื่อมต่อบริการ Nota ที่รองรับเพื่อซิงก์ได้ บริการออนไลน์ที่ผู้ใช้เชื่อมต่อมีการจัดการข้อมูลบนเซิร์ฟเวอร์แยกจากข้อมูลในเครื่อง โปรดตรวจนโยบายของผู้ให้บริการนั้นก่อนเชื่อมบัญชี

ข้อมูลที่แอพใช้และวัตถุประสงค์

แอพเก็บชื่อและเนื้อหาโน้ต โฟลเดอร์ ฉบับร่าง รายการรอซิงก์ สถานะปักหมุด ถังขยะ และไฟล์แนบที่ผู้ใช้เลือกในพื้นที่ข้อมูลของแอพ เพื่อให้สร้าง แก้ไข ค้นหา กู้คืน และใช้งานออฟไลน์ได้ เนื้อหาเหล่านี้อาจมีข้อมูลส่วนบุคคลที่ผู้ใช้ใส่เอง

แอพเก็บการตั้งค่า เช่น ธีม ขนาดคอลัมน์ และตำแหน่งโน้ตล่าสุดในเครื่อง เพื่อให้ผู้ใช้กลับมาทำงานต่อได้ ข้อมูลที่เก็บเฉพาะเครื่องไม่ได้ถูกส่งให้ AooBC โดยอัตโนมัติเพียงเพราะสร้างหรือแก้ไขโน้ต

ไฟล์แนบ การนำเข้า และการสำรอง

ไฟล์ที่ผู้ใช้แนบจะถูกคัดลอกเข้าสู่พื้นที่ข้อมูลของแอพ รูปภาพแสดงในโน้ต ไฟล์อื่นเปิดหรือบันทึกได้ตามคำสั่งของผู้ใช้ ไฟล์แนบ local ไม่ซิงก์ bytes ไปยังเครื่องอื่นในรุ่นนี้ แต่ข้อมูลอ้างอิงไฟล์อาจอยู่ในเนื้อหาที่ซิงก์

การนำเข้า ส่งออก และสำรองทำตามคำสั่งของผู้ใช้ สำเนาที่ส่งออกหรือสำรอง อาจมีข้อมูลส่วนตัวและไฟล์แนบ ผู้ใช้เลือกตำแหน่งเก็บและควบคุมการส่งต่อสำเนาเหล่านั้น

การเข้าสู่ระบบและซิงก์

เมื่อเลือกเชื่อมบัญชี แอพเปิดเบราว์เซอร์เพื่อเข้าสู่บริการที่กำหนด และรับ ID บัญชี อีเมล ชื่อหากมี สถานะตรวจสอบอีเมล และ token ยืนยันสิทธิ์ ข้อมูลเหล่านี้ใช้ระบุบัญชี ผูกคลัง และอนุญาตการซิงก์ credentials ที่เก็บในเครื่องได้รับการเข้ารหัสผ่านกลไกของระบบปฏิบัติการ

เมื่อเปิดซิงก์ แอพรับส่งข้อความโน้ต โฟลเดอร์ ID เวอร์ชัน และข้อมูลการเปลี่ยนแปลง กับเซิร์ฟเวอร์ที่ผู้ใช้เชื่อมต่อ การเชื่อมต่อ production ใช้ HTTPS การซิงก์อาจเกิดขึ้นอัตโนมัติขณะเปิดใช้งานหลังเชื่อมบัญชีแล้ว ผู้ให้บริการออนไลน์อาจได้รับข้อมูลการเชื่อมต่อ เช่น IP เพื่อให้บริการดังกล่าว

ผู้ใช้หยุดซิงก์ได้โดยออกจากระบบ ซึ่งนำ credentials ในเครื่องออก แต่ไม่ลบโน้ตในเครื่องหรือข้อมูลบนเซิร์ฟเวอร์ ระยะเก็บรักษา ประเทศที่จัดเก็บ ผู้ประมวลผลข้อมูล และการลบบัญชีบนเซิร์ฟเวอร์ขึ้นกับผู้ให้บริการที่เลือก หากไม่มีนโยบายและช่องทางติดต่อของบริการนั้น ผู้ใช้ยังสามารถใช้งาน local ได้

การแชร์ ลิงก์ และรูปภาพออนไลน์

หากผู้ใช้เปิดแชร์สาธารณะสำหรับโน้ตที่รองรับ เนื้อหาจะเข้าถึงได้ผ่านลิงก์ ของบริการที่เชื่อมต่อ ผู้รับอาจเก็บสำเนาไว้ได้แม้ภายหลังปิดแชร์แล้ว โปรดตรวจสอบเนื้อหาก่อนแชร์

ลิงก์ภายนอกเปิดผ่านเบราว์เซอร์ของระบบ การโหลดรูปภาพหรือทรัพยากรออนไลน์ ที่โน้ตอ้างอิงอาจส่งข้อมูลการเชื่อมต่อ เช่น IP ไปยังผู้ให้บริการทรัพยากรนั้น แม้ไม่ได้เปิดซิงก์ การใช้งานเว็บไซต์ภายนอกอยู่ภายใต้นโยบายของเว็บไซต์นั้น

การเก็บรักษาและการลบ

ข้อมูล local อยู่ในเครื่องเพื่อให้เปิดกลับมาใช้งานได้ ถังขยะ local ไม่มีการล้าง อัตโนมัติ การย้ายเข้าถังขยะไม่ใช่การลบข้อมูลบนเซิร์ฟเวอร์ทันที การลบถาวรของโน้ตที่ซิงก์ใช้คิวลบและต้องติดต่อเซิร์ฟเวอร์สำเร็จ สำเนาที่ส่งออก สำรอง หรือถูกบุคคลอื่นเก็บไว้ต้องจัดการแยกกัน

การถอนติดตั้งหรือออกจากระบบไม่รับประกันว่าข้อมูลทั้งหมดถูกลบ หากต้องการล้างข้อมูล local ทั้งหมด กรุณาติดต่อเราเพื่อรับคำแนะนำ ก่อนจัดการพื้นที่ข้อมูลของแอพ โดยควรสำรองข้อมูลที่ยังต้องการเก็บไว้

ความปลอดภัยและทางเลือกของผู้ใช้

การเข้ารหัส credentials ไม่ใช่การเข้ารหัสฐานข้อมูลโน้ตทั้งหมดหรือ end-to-end encryption ผู้ที่มีสิทธิ์เข้าถึงไฟล์ในเครื่องอาจเข้าถึงข้อมูล local ได้ ผู้ใช้ควรป้องกันบัญชี Windows อุปกรณ์ และสำเนาสำรองของตน

ผู้ใช้เลือกใช้ local โดยไม่เชื่อมบัญชี แก้ไขหรือส่งออกโน้ต หยุดซิงก์ และจัดการการแชร์ได้ตามฟังก์ชันของแอพและบริการที่เชื่อมต่อ
